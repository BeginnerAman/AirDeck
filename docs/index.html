Engineered for Sub-Millisecond Input Latency

Unlike traditional remote control software that chokes Python event loops with synchronous operating system calls, AirDeck Pro decouples network ingestion from OS hardware execution.

  • Direct Win32 SendInput (ctypes)
    Bypasses high-level wrapper overhead for instant OS hardware cursor injection.
  • 1ms Multimedia Timer (winmm.timeBeginPeriod)
    Forces Windows kernel scheduler resolution from default 15.6ms down to 1.0ms.
  • Zero-Trust Constant-Time Auth
    Constant-time token validation, anti-brute-force rate limiting, and local TLS encryption.

Frequently Asked Questions

Everything you need to know

Do I need to install any mobile app from the Play Store or App Store?
No. AirDeck Pro works entirely through standard web browser protocols (WebSockets, WebRTC, Canvas, and Service Workers). You can use Chrome, Safari, Edge, or Samsung Internet, and optionally tap "Add to Home Screen" for a full-screen app experience.
Does AirDeck work without active internet access?
Yes. AirDeck Pro communicates strictly over your local area network (LAN) or mobile hotspot. It requires zero cloud connectivity and works perfectly on flights, outdoors, or offline local networks.
Why does the browser display an SSL certificate prompt on first visit?
Modern mobile browsers strictly require HTTPS to grant microphone and camera permissions. AirDeck generates a persistent self-signed root certificate for your local IP. You can bypass the warning with one tap ("Proceed to site") or install the certificate on your phone to permanently eliminate warnings.
How do I use my phone microphone inside Discord or Zoom?
Install the free VB-Audio Virtual Cable on your Windows PC. When you toggle the Mic button on Deck 1, AirDeck pipes the phone audio into CABLE Input. In Discord or Zoom, simply select "CABLE Output" as your input microphone.
Can I run AirDeck silently in the background on Windows startup?
Yes. AirDeck has built-in Windows System Tray integration. You can enable "Run on Windows Startup" directly inside the desktop Control Panel or via the Windows registry autostart manager.
